About the Prediction
The model uses Random Forest Regression trained on historical processing data including bird counts, weight, mortality, transit shrinkage, yield %, prices, and operating costs. Predictions are generated for each day of the next calendar month using seasonal patterns derived from historical same-month data.

Features used: Live Birds, Average Bird Weight, Mortality %, Transit Shrinkage %, Yield %, Live Bird Price, Operating Cost/Kg, By-Product Income/Kg, Transport Cost/Kg, Month, Day of Week, Week of Year.
